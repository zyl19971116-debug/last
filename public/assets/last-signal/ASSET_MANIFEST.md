# Asset manifest

- `hero-world.png`: generated original cinematic environment; replaceable independently.
- Mechanical gateway, text, countdown, buttons, status, cards, and panels are rendered in HTML/CSS.
- Future optional layers: transparent atmospheric dust WebP, mobile-specific background crop, OpenGraph cover.

## Cinematic rebuild V3

Generated with the built-in ImageGen workflow using the user-provided design as composition and mood reference. All assets intentionally contain no UI text, buttons, cards, numbers, or logos.

- `cinematic/hero-environment.webp`: complete portal landscape, distant planet, ships, ruins, fog and reflective ground.
- `cinematic/portal-ring.webp`: transparent front-facing mechanical ring compositing layer.
- `cinematic/energy-beam.webp`: transparent narrow crimson energy VFX layer.
- `cinematic/crystal-environment.webp`: wide faceted crystal altar environment for the protocol section.

The title, navigation, countdown, epoch state, statistics, actions and activity feed remain real HTML and application data.
